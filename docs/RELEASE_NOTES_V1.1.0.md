# Version 1.1.0 release notes

Version 1.1.0 aligns the public repository with the analysis used in the Geriatrics & Gerontology International submission.

## Substantive update

- Replaces the former biomarker-complete CHARLS primary workflow with the grip-focused primary cohort.
- The updated CHARLS primary sample contains 3,767 participants, 6,689 person-periods and 1,010 events.
- The primary estimate is HR 1.213772 (95% CI 1.119082–1.316474) per one-standard-deviation greater grip decline.
- Preserves the ELSA conceptual-replication workflow used for the submission.
- Adds machine-readable, aggregate reference results for submission-to-code verification.
- Updates path configuration, citation metadata and documentation. Restricted participant-level data remain excluded.

Version 1.0.0 remains available as the historical archive of the earlier biomarker-complete workflow.
