# Release notes: v1.2.0

Released 28 October 2026.

## Added

- Reproducible sensitivity-analysis scripts for Supplementary Tables S16-S18.
- Aggregate reference results for the skip-path, covariate, scale, age,
  Model B-versus-C, and BMI/CES-D10 analyses.
- Configuration entries and documentation for local sensitivity outputs and
  the optional historical V1 cohort audit.

## Privacy and licensing

No individual-level CHARLS or ELSA data, identifiers, credentials, or local
filesystem paths are included. Only original project code and aggregate
reference results are released under the MIT License.

## Compatibility

The primary and previously released secondary workflows are unchanged from
v1.1.0. Version 1.2.0 extends the archive; it does not replace or alter the
reported primary estimates.
